DAVID BLOG · 写作台

写文章

写好后直接提交到博客仓库。GitHub Pages 会按现有 Jekyll 流程发布文章。

主题使用博客现有的标签机制，发布后会出现在归档页。

只用小写英文字母、数字和连字符。留空则自动生成唯一链接名。

标题、主题和正文会自动保存在这台设备的浏览器中。令牌不会保存。

预览将提交的 Markdown 文件 

      


      

        
        
        
在 GitHub 创建 Fine-grained PAT，仓库只选 gymdarius.github.io，Contents 设为 Read and write。令牌仅用于直接请求 GitHub API，不会写进文章、草稿或网站文件。
